ORCA — файловый менеджер для Windows (в духе Dolphin из KDE)

ПРОЩЕ ВСЕГО: запустите установщик Orca-Setup-<версия>.exe (если он есть рядом) — он установит программу, создаст ярлыки и добавит
удаление в «Параметры → Приложения». Ниже — вариант без установки (портативный).

КАК ЗАПУСТИТЬ
1. Распакуйте архив целиком в любую папку (например, D:\Programs\Orca).
   Не запускайте из архива и не выдёргивайте один exe: рядом должна лежать папка _internal.
2. Откройте Orca.exe. Установка и Python не нужны. Нужна Windows 10 или 11.
3. Можно сделать ярлык: правой кнопкой на Orca.exe -> «Отправить» -> «Рабочий стол (создать ярлык)».

ЕСЛИ WINDOWS РУГАЕТСЯ
Программа не подписана цифровой подписью, поэтому SmartScreen может написать
«Windows защитила ваш компьютер». Нажмите «Подробнее» -> «Выполнить в любом случае».
Антивирус тоже может проверять первый запуск дольше обычного.

ГЛАВНЫЕ КЛАВИШИ
Ctrl+T / Ctrl+W      новая / закрыть вкладка
F3                   две панели;  F7 / F8 — копия / перенос в другую панель
Ctrl+F               поиск в папке и во всех вложенных
Ctrl+I               фильтр по имени
Ctrl+L или F6        ввести путь
Ctrl+1 … 8           перейти на вкладку по номеру (Ctrl+9 — на последнюю)
Ctrl+Shift+1 / 2 / 3 вид: значки / компактно / подробно
Ctrl + колесо мыши   размер значков
Ctrl+C / X / V       копировать / вырезать / вставить
F2                   переименовать
Delete               в корзину;  Shift+Delete — навсегда
F10 или Ctrl+Shift+N новая папка
Ctrl+Z               отменить (переименование, создание папки, копирование, перенос)
Ctrl+H               скрытые файлы
F9 / F11             боковая панель / панель сведений
Ctrl+D               добавить папку в закладки
Колёсико мыши на папке — открыть в новой вкладке
Остальное — в меню «⋯» справа вверху -> «Горячие клавиши».

ГДЕ ХРАНЯТСЯ НАСТРОЙКИ
%APPDATA%\Provodnik\settings.json (вкладки, закладки, тема). Удалите файл — всё сбросится.
Сама программа файлы не удаляет без вашего действия: удаление идёт в корзину.

БЕЗОПАСНОСТЬ
Удаление по умолчанию идёт в КОРЗИНУ Windows (оттуда можно восстановить). Для 5+ объектов и для папок Orca спрашивает подтверждение.
Журнал всех копирований, переносов и удалений: %APPDATA%\Provodnik\actions.log — если что-то пропало, пришлите этот файл.


ПЕРЕТАСКИВАНИЕ
Файлы можно тащить мышью: на папку, на вкладку, на часть пути в адресной строке, на место или диск в боковой панели, на вторую панель и в другие программы. На том же диске файлы переносятся, на другой диск копируются; Ctrl — всегда копия, Shift — всегда перенос.
Миниатюры: у картинок, видео, PDF и музыки в режиме «Значки» (Ctrl+Shift+1).


НОВОЕ
Пробел — быстрый просмотр файла (картинки, текст, видео, PDF, папки); стрелки — другой файл; Esc — закрыть.
F4 — терминал в текущей папке.  Ctrl+M — цветная метка у файла или папки.
«⋯» → «Найти дубликаты…» (по содержимому, лишнее — только в корзину) и «Сравнить папки двух панелей…».
Архивы .zip открываются как папки (Enter); .apk/.jar и др. — «Открыть как папку» через путь в адресной строке.

ВЕРСИЯ 1.2
Версию смотрите в «⋯» → «О программе»; список изменений — «⋯» → «Что нового» (после обновления он покажется сам).
Ctrl+Shift+T — вернуть закрытую вкладку;  Ctrl+N — новое окно;  Ctrl+S — выделить по маске (*.jpg; IMG_*);
Ctrl+Shift+I — инвертировать выделение. В боковой панели появился раздел «Недавние».
Правая кнопка: «Посчитать размер» (папки), «Контрольные суммы…» (MD5/SHA-1/SHA-256 с проверкой).
«⋯» → «Всегда спрашивать перед удалением» — подтверждение даже для одного файла.
Если Orca вылетит — пришлите файл %APPDATA%\Provodnik\orca.log.

ВЕРСИЯ 1.3
Ctrl+Shift+F — поиск по всему ПК через Everything (если она установлена; Orca сама запустит её в фоне). Результаты мгновенные
и не тормозят даже на сотнях тысяч файлов; пишите по-everything: *.jpg, ext:pdf, size:>1gb, dm:today.
F2 на нескольких файлах — массовое переименование с предпросмотром (Ctrl+Z отменяет). Ctrl+Shift+P — быстрые команды.

ВЕРСИЯ 1.4 — НАСТРОЙКИ
Ctrl+, (или «⋯» → «Настройки…»): свои горячие клавиши для любого действия (выберите действие → нажмите сочетание → «Назначить»),
что открывать при запуске, вид и тема по умолчанию, скрытые файлы, подтверждение удаления, поиск через Everything.
