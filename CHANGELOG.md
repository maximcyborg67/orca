# Журнал изменений Orca

## 1.5.0 — 14.10.2026

### Новое
- **Своё окно «Свойства»** в стиле Orca вместо системного (`Alt+Enter`, правая кнопка, боковая панель). Показывает тип, расположение, размер (в байтах и «на диске» с учётом кластеров), даты создания / изменения / открытия, число файлов и папок внутри (считается в фоне, не мешает работать). Для нескольких объектов — общий размер. Для диска — занято / свободно / ёмкость. Атрибуты «Только чтение» и «Скрытый» можно менять прямо там. Кнопки «Контрольные суммы…» и «Системные свойства…» (окно Windows с безопасностью и предыдущими версиями). (Предложил Ricke.)

### Изменено
- **Работа с телефоном по ADB убрана** из программы: пока она не проверена на настоящих телефонах, лучше не обещать лишнего. Раздел «Телефон (ADB)…» в боковой панели и кнопка «Указать adb.exe» в настройках исчезли. Архивы `.zip` как папки работают, как раньше.

## 1.4.0 — 14.10.2026

### Новое
- **Окно «Настройки»** — `Ctrl+,` или «⋯» → «Настройки…».
  - **Свои горячие клавиши для любого действия** (их больше 70): выберите действие, нажмите нужное сочетание, «Назначить». Если сочетание занято, Orca спросит, отобрать ли его. Можно убрать клавишу, вернуть стандартную или сбросить все. Подсказки на кнопках и меню сразу показывают новые клавиши, настройки сохраняются.
  - **Что открывать при запуске:** то, что было в прошлый раз, домашнюю папку или любую выбранную папку.
  - **Вид папок по умолчанию**, тема, показ скрытых файлов, подтверждение удаления, поиск через Everything — всё в одном месте.
- «Горячие клавиши…» теперь открывает ту же вкладку с актуальным списком (раньше был статичный текст, который устаревал).
- Действия без клавиши по умолчанию («Найти дубликаты», «Сравнить папки», «Обновить индекс» и др.) тоже можно повесить на любую клавишу.

## 1.3.1 — 14.10.2026

### Изменено
- **Горячие клавиши как в браузере:** `Ctrl+1 … Ctrl+8` переключают вкладки по номеру, `Ctrl+9` — на последнюю вкладку. Переключение вида (значки / компактно / подробно) перенесено на `Ctrl+Shift+1 / 2 / 3`. Подсказки на кнопках и окно «Горячие клавиши» обновлены. (Предложил Ricke.)

## 1.3.0 — 14.10.2026

### Новое
- **Поиск по всему ПК через Everything** (`Ctrl+Shift+F`). Если у вас установлена Everything (voidtools), Orca использует её базу: результаты за доли секунды, поиск идёт по мере набора, работает синтаксис Everything (`*.jpg`, `ext:pdf`, `size:>1gb`, `dm:today`). Если Everything не запущена — Orca сама запустит её в фоне. Без Everything всё работает по-старому (собственный индекс).
- **Список результатов больше не тормозит**: показываются только видимые строки, поэтому хоть миллион найденных файлов — окно отзывчивое (раньше каждая найденная строка создавалась отдельно и всё «лагало»). Сортировка по имени / папке / размеру / дате делается самой Everything.
- **Массовое переименование** — выделите несколько файлов и нажмите `F2`: заменить текст (в том числе регулярным выражением), добавить в начало/конец, пронумеровать, сменить регистр. Перед применением — таблица «было → станет» с проверкой повторов и запрещённых символов; `Ctrl+Z` возвращает всё обратно.
- **Быстрые команды** — `Ctrl+Shift+P`: начните вводить название действия («дубли», «вкладка», «метка») и нажмите Enter.
- **Копировать имена файлов** (без путей) — в меню правой кнопки.
- «⋯» → «Искать через Everything» — переключатель.

### Исправлено
- Телефон (ADB): сообщение «положите adb.exe в D:\platform-tools» ссылалось на чужой диск. Теперь Orca ищет `adb.exe` на всех дисках и в обычных местах, а если не нашла — понятно объясняет и даёт указать файл вручную (запоминает).

## 1.2.0 — 14.10.2026

### Новое
- **Версия и «О программе».** В меню «⋯» → «О программе»: номер версии, дата, служебные пути. Версия видна и в свойствах `Orca.exe`, и в названии установщика.
- **Журнал изменений** прямо в программе («⋯» → «Что нового»). После обновления окно с новинками показывается один раз само.
- **Вернуть закрытую вкладку** — `Ctrl+Shift+T` (помнит последние 15).
- **Недавние папки** — новый раздел в боковой панели (последние 8, можно убрать из списка по правой кнопке).
- **Размер папки** — «Посчитать размер» в меню правой кнопки: считает в фоне, не мешает работе.
- **Контрольные суммы файла** (MD5, SHA-1, SHA-256) — в меню правой кнопки; можно вставить ожидаемую сумму и сразу увидеть, совпала ли.
- **Выделить по маске** — `Ctrl+S` (например `*.jpg; IMG_*`) и **инвертировать выделение** — `Ctrl+Shift+I`.
- **Новое окно** — `Ctrl+N`: открывает ещё одно окно Orca в текущей папке.
- **«Всегда спрашивать перед удалением»** — переключатель в «⋯»: подтверждение даже для одного файла.

### Исправлено
- Редкий вылет без причины (Qt, код `0xc0000409`): фоновые потоки отпускались чуть раньше, чем останавливались. Исправлено во всех местах — перенос и копирование, чтение папок, поиск, индекс файлов, закрытие вкладок.
- Тот же сбой в построителе индекса файлов (после окончания индексации).
- Убраны неиспользуемые части кода; тема «Стекло» удалена полностью.
- Появился журнал `orca.log` в `%APPDATA%\Provodnik` — если что-то случится, причина запишется туда.

## 1.1.0 — 14.10.2026
- Тёмная и светлая темы, быстрая работа с огромными папками (30 000 файлов — за доли секунды).
- Миниатюры видео, PDF и музыки в режиме «Значки» (средствами Windows); значки файлов подгружаются в фоне.
- Быстрый просмотр по пробелу, цветные метки (`Ctrl+M`), терминал (`F4`).
- Поиск дубликатов (по содержимому) и сравнение папок двух панелей.
- Архивы `.zip` открываются как папки; телефон по ADB («Телефон (ADB)…» в боковой панели).
- Поиск по всем дискам через индекс файлов.
- Установщик `Orca-Setup.exe`.
- Подтверждения при удалении папок и 5+ файлов, журнал действий `actions.log`.
- Перетаскивание на вкладки, части пути и боковую панель.

## 1.0.0 — 14.10.2026
- Первая версия: вкладки, две панели, боковая панель, адресная строка с кликабельными частями, три вида (значки / компактно / подробно), фильтр и поиск, копирование / перенос / корзина через Windows, отмена `Ctrl+Z`, панель сведений, родное меню Windows.
